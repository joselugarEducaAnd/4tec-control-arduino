14. Preparar el examen

Qué vas a conseguir. Repasar todo lo de la unidad antes del examen escrito, que es individual, en papel y sin apuntes.

Qué entra

  • Las partes de un sistema de control y la diferencia entre lazo abierto y cerrado, con diagramas de bloques.
  • La placa Arduino: pines digitales, analógicos y con ~, y qué hace cada orden.
  • Leer un programa y decir qué hace, y completar huecos de un programa.
  • Cálculos de map, de lecturas de analogRead y de distancias con ultrasonidos.
  • El servo, el sensor de ultrasonidos y el driver de un motor: conexiones y programación.
  • Elegir pines y componentes para un sistema sencillo.
  • Usar el monitor serie para medir, para elegir un umbral con las lecturas y para buscar fallos como los de las tablas «Si falla…» de la unidad.

En el examen no hay chuleta ni apuntes, así que repasa también las órdenes, que tendrás que escribir tú. La chuleta sirve para estudiar.

Cómo se corrige. Escribe siempre las operaciones: un resultado sin operaciones no puntúa. Las unidades cuentan: una distancia sin «cm» vale la mitad. Un ; olvidado o una mayúscula no restan si la orden se entiende; lo que cambia lo que hace el programa (un = en lugar de ==, un < en lugar de >) sí.

Practica

Ahora tú. Un pin analógico recibe 2 V. ¿Qué número devuelve analogRead, más o menos?

Ver solución

2 / 5 · 1023 ≈ 409.

Ahora tú. Escribe la orden que convierte una lectura de 0 a 1023 en un brillo de 0 a 255 para analogWrite.

Ver soluciónint brillo = map(lectura, 0, 1023, 0, 255);

Ahora tú. ¿Qué hace este programa?

void loop() {
  if (digitalRead(2) == LOW && analogRead(A1) < 300) {
    digitalWrite(12, HIGH);
  } else {
    digitalWrite(12, LOW);
  }
}
Ver solución

Enciende el LED del pin 12 solo cuando el pulsador del pin 2 está pulsado (da LOW) y además hay poca luz (lectura de A1 menor que 300). En cualquier otro caso, lo apaga.

Ahora tú. El sensor de ultrasonidos mide un eco de 2915 µs. ¿A qué distancia está el obstáculo?

Ver solución

d = 2915 · 0,0343 / 2 ≈ 50 cm.

Ahora tú. Con IN1 = HIGH, IN2 = HIGH y analogWrite(EN, 200), ¿qué hace el motor?

Ver solución

Está parado (frenado): con IN1 e IN2 iguales no gira, aunque EN tenga velocidad.

Ahora tú. Una alarma de calor se enciende con más de 30 °C y se apaga con menos de 28 °C. Con 29 °C, ¿está encendida o apagada?

Ver soluciónDepende de cómo estaba: 29 °C está entre los dos umbrales, y con histéresis se queda como estaba.

Ahora tú. Clasifica: el control de crucero de un coche, que mantiene la velocidad aunque haya cuestas.

Ver soluciónLazo cerrado: mide la velocidad, que es justo lo que controla, y acelera o suelta para corregirla.

Antes del examen, comprueba que sabes…

  • escribir de memoria la estructura setup() y loop();
  • decir qué hacen pinMode, digitalWrite, digitalRead, analogRead, analogWrite, delay y map;
  • escribir un if con else y un for;
  • explicar por qué hace falta un driver para un motor y qué hacen EN, IN1 e IN2;
  • calcular una distancia con el tiempo del eco;
  • escribir las dos órdenes que hacen falta para ver un valor en el monitor serie;
  • explicar qué es la histéresis y para qué sirve.
