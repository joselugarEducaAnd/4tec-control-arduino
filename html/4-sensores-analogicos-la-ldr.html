Sistemas que reaccionan

4. Sensores analógicos: la LDR

Qué vas a conseguir. Leer un sensor analógico con analogRead, ver sus valores en el monitor serie y encender una salida cuando se pasa de un umbral elegido con medidas reales.

Leer una tensión: analogRead

Un pulsador solo tiene dos estados, pero un sensor de luz o de temperatura da valores intermedios. Los pines A0 a A5 leen cualquier tensión entre 0 y 5 V y la convierten en un número entero de 0 a 1023: 0 V da 0, 5 V da 1023 y 2,5 V da unos 512.

lectura = analogRead(A1);

En el shield hay dos componentes analógicos que vas a usar mucho: el potenciómetro (A0) y la LDR (A1). La LDR está montada en un divisor de tensión, como los que montaste en la unidad de electrónica analógica:

Ver lo que lee: el monitor serie

El Arduino puede enviar números al ordenador por el cable USB. Así puedes «espiar» lo que está leyendo:

Ejemplo: escribir la lectura de la LDR en el monitor serie

// Ver en el monitor serie lo que lee la LDR del shield (A1)
const int LDR = A1;

void setup() {
  Serial.begin(9600);           // abre la comunicación con el ordenador
}

void loop() {
  int luz = analogRead(LDR);    // de 0 (0 V) a 1023 (5 V)
  Serial.println(luz);          // escribe el número en una línea nueva
  delay(300);
}
  • Serial.begin(9600); abre la comunicación. Va en setup().
  • Serial.println(luz); escribe el valor de luz y salta a una línea nueva.
  • En Arduino IDE, el monitor serie se abre con el botón Monitor Serial (el de la lupa, arriba a la derecha). En Tinkercad, con Monitor en serie, debajo del código.

Ahora tú. Sube el ejemplo a tu placa y abre el monitor serie. Anota la lectura con la luz del aula y con la LDR tapada con el dedo. ¿Cuál es mayor?

Ver solución

Con luz, la lectura es mayor; tapada, mucho menor. Los números exactos dependen de la luz del aula y de cada LDR: por eso cada persona mide los suyos.

Añade los sensores a tu Shield virtual

Abre tu Shield virtual (el original) y añádele los tres sensores analógicos del shield en una segunda placa de pruebas, debajo del Arduino: arriba quedan las luces y los pulsadores; abajo, los sensores.

  1. Arrastra una Placa de pruebas pequeña debajo del Arduino. Lleva un cable del pin 5V al carril + de arriba de esta placa y otro de un pin GND al carril −. Del mismo pin pueden salir varios cables.
  2. Coloca un Potenciómetro con sus patillas en h12, h13 y h14. Une j12 con el carril +, j14 con el carril − y j13 (la patilla del centro) con el pin A0.
  3. Coloca una Fotorresistencia (la LDR) en f17 y f18. Une j17 con el carril + y pon una Resistencia de 10 kΩ de j18 al carril −. Lleva un cable de i18 al pin A1: es el divisor del esquema de arriba.
  4. Coloca un Sensor de temperatura en f22, f23 y f24. Pasa el ratón por sus patillas: la de la izquierda es la alimentación (de j22 al carril +), la de la derecha es la tierra (de j24 al carril −) y la del centro, la señal (de j23 al pin A2).

Para probarlo, duplica el Shield virtual y llama a la copia Reto R3 - Farola. Pega en ella este programa e inicia la simulación. Mientras simula, puedes cambiar lo que mide cada sensor:

Programa de prueba de los sensores

// Prueba de los sensores del Shield virtual: potenciómetro (A0), LDR (A1) y temperatura (A2)
const int POT = A0;
const int LDR = A1;
const int SENSOR_T = A2;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int pot = analogRead(POT);
  int luz = analogRead(LDR);
  analogRead(SENSOR_T);    // lectura de descarte: la buena es la siguiente
  delay(10);
  float voltios = analogRead(SENSOR_T) * 5.0 / 1023;
  float grados = (voltios - 0.5) * 100;    // fórmula del sensor de temperatura de Tinkercad
  Serial.print("Pot: ");
  Serial.print(pot);
  Serial.print("   Luz: ");
  Serial.print(luz);
  Serial.print("   Temperatura: ");
  Serial.print(grados, 1);
  Serial.println(" C");
  delay(500);
}
Si el potenciómetro va al revés. En el shield, la lectura del potenciómetro sube al girarlo en el sentido de las agujas del reloj. Si en tu Shield virtual baja, intercambia los cables de j12 y j14.

Decidir con un umbral

Un umbral es un valor límite: si la lectura queda por debajo, se hace una cosa; si queda por encima, otra. Primero, un ejemplo con el potenciómetro:

Ejemplo: si el potenciómetro pasa de la mitad, se enciende el LED azul

// Si el potenciómetro pasa de la mitad, se enciende el LED azul
const int POT = A0;
const int LED_AZUL = 13;
const int UMBRAL = 512;         // la mitad de 1023, más o menos

void setup() {
  pinMode(LED_AZUL, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int valor = analogRead(POT);
  Serial.println(valor);
  if (valor > UMBRAL) {
    digitalWrite(LED_AZUL, HIGH);
  } else {
    digitalWrite(LED_AZUL, LOW);
  }
  delay(100);
}

Con la LDR es igual: «si hay poca luz, enciende la farola». Prueba en el simulador qué pasa al cambiar la luz y el umbral:

Idea clave. El umbral no se inventa: se mide. Si con luz lees 700 y tapada 150, un umbral de 400 queda bien en medio.

El reto de hoy

Reto R3 · Farola automática

El LED rojo (12) es una farola. Mide los valores de tu LDR con luz y tapada, elige tu umbral y programa la farola para que se encienda cuando hay poca luz y se apague cuando hay luz. Primero en Tinkercad, en tu copia Reto R3 - Farola (durante la simulación, haz clic en la LDR para cambiar la luz), y después en tu placa.

Está conseguido cuando… en tu placa, al tapar la LDR la farola se enciende y al destaparla se apaga, y el umbral del programa sale de tus medidas.

Si te atascas: el programa con huecos

Rellena cada ____: cada hueco es una palabra, un número o un signo que ya has visto en esta página.

// Reto R3: farola automática con la LDR del shield
const int LDR = A1;
const int FAROLA = 12;          // el LED rojo hace de farola
int umbral = ____;               // pon aquí TU umbral, medido

void setup() {
  pinMode(FAROLA, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int luz = ____;
  Serial.println(luz);
  if (luz ____ umbral) {             // poca luz: es de noche
    digitalWrite(FAROLA, HIGH);
  } else {
    digitalWrite(FAROLA, ____);
  }
  delay(200);
}

Cuando funcione en la placa: enséñalo funcionando para que se anote en la lista de los retos. Después, en la tarea de Moodle Retos Arduino (código), pulsa Editar entrega (la primera vez, Agregar entrega), escribe R3 y pega debajo tu programa. Pulsa Guardar cambios. Cada reto nuevo va debajo del anterior.

Para ir más allá. Que el umbral lo fije el potenciómetro: en cada vuelta de loop(), guarda en umbral la lectura de A0. Así se ajusta sin tocar el programa.
