Sistemas que reaccionan

6. Motores con driver

Qué vas a conseguir. Controlar el sentido y la velocidad de un motor de corriente continua con un driver, y entender por qué el Arduino no puede alimentar el motor directamente.

Por qué hace falta un driver

Un pin del Arduino puede dar unos 20 mA sin sufrir. Un motor pequeño necesita mucha más corriente, sobre todo al arrancar. Si lo conectas directamente al pin, el motor no gira bien y el Arduino se puede estropear.

La solución es un driver: un circuito que recibe las órdenes del Arduino (con muy poca corriente) y deja pasar hacia el motor la corriente de otra fuente. Es la misma idea que el transistor como interruptor de la unidad de electrónica analógica, pero con cuatro interruptores.

El puente en H

Para que un motor gire al revés hay que darle la vuelta a la corriente. El puente en H lo consigue con cuatro interruptores alrededor del motor:

Nuestro driver, el L293D, lleva dentro dos puentes en H hechos con transistores. Tú solo le das tres órdenes por motor:

Patilla del driverPin del ArduinoQué controla
EN1 (patilla 1)5 (con ~)La velocidad, con analogWrite: 0 parado, 255 a tope
IN1 (patilla 2)8El sentido, junto con IN2
IN2 (patilla 7)7El sentido, junto con IN1
IN1IN2El motor…

LOWHIGHgira al revés

Ahora tú. ¿Qué hace el motor con IN1 = LOW, IN2 = HIGH y analogWrite(EN, 0)?

Ver solución

Está parado: el sentido está elegido, pero la velocidad es 0.

El montaje (sin shield)

El shield ya tiene ocupados casi todos los pines, así que el motor se monta sin shield: quítalo con el USB desconectado y guárdalo. El driver va en la protoboard y el motor se alimenta del módulo de 5 V de la protoboard, el mismo de la unidad de electrónica analógica.

Idea clave. Las GND del Arduino, del módulo (en Tinkercad, la fuente) y del driver tienen que estar unidas. Sin esa unión, las órdenes del Arduino no significan nada para el driver.

Ejemplo: un sentido, parada y el otro sentido

// Motor con driver L293D: un sentido, parada y el otro sentido
const int EN = 5;                // EN del driver: la velocidad (pin con ~)
const int IN1 = 8;               // IN1 e IN2: el sentido de giro
const int IN2 = 7;

void setup() {
  pinMode(EN, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
}

void loop() {
  digitalWrite(IN1, HIGH);       // gira en un sentido
  digitalWrite(IN2, LOW);
  analogWrite(EN, 200);
  delay(2000);
  analogWrite(EN, 0);            // parado
  delay(1000);
  digitalWrite(IN1, LOW);        // gira al revés
  digitalWrite(IN2, HIGH);
  analogWrite(EN, 200);
  delay(2000);
  analogWrite(EN, 0);
  delay(1000);
}

Repetir con un contador: for

Para que el motor acelere poco a poco hay que ir subiendo la velocidad paso a paso. El bucle for repite unas órdenes cambiando un número cada vez:

for (int v = 100; v <= 255; v = v + 5) {
  analogWrite(EN, v);
  delay(50);
}
ParteSignifica
int v = 100Empieza con v valiendo 100.
v <= 255Repite mientras v sea menor o igual que 255.
v = v + 5Al final de cada vuelta, suma 5 a v.

Ejemplo: el motor acelera poco a poco

// El motor acelera poco a poco con un bucle for
const int EN = 5;
const int IN1 = 8;
const int IN2 = 7;

void setup() {
  pinMode(EN, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
}

void loop() {
  for (int v = 100; v <= 255; v = v + 5) {   // v vale 100, 105, 110... hasta 255
    analogWrite(EN, v);
    delay(50);
  }
  analogWrite(EN, 0);                         // al terminar, se para
  delay(2000);
}

Ahora tú. ¿Cuántas vueltas da este for y cuánto tarda en total, más o menos?

Ver soluciónv vale 100, 105… hasta 255: (255 − 100) / 5 + 1 = 32 vueltas. Cada una espera 50 ms: unos 1,6 segundos.

En Tinkercad

Aquí no se parte del Shield virtual, porque el motor se monta sin shield. Crea un diseño nuevo llamado Reto R5 - Motor con: Arduino Uno R3, Placa de pruebas pequeña, Controlador de motor de puente H (es el L293D; colócalo cruzando la ranura central) y Motor de aficionado. Si acercas el ratón a cada patilla del chip, Tinkercad te dice su nombre: «Activar 1 y 2» es EN1, «Entrada 1» y «Entrada 2» son IN1 e IN2, y «Potencia 1» y «Potencia 2» son las dos alimentaciones. Para el motor, añade una Fuente de alimentación a 5 V, que hace de módulo de la protoboard, y monta todo como en la captura de arriba.

El reto de hoy

Reto R5 · Arranque suave y cambio de sentido

Primero averigua con qué velocidad arranca tu motor: prueba analogWrite(EN, …) con 60, 80, 100… hasta que gire. Ese es tu arranque. Después programa la secuencia: el motor acelera desde tu arranque hasta 255, se para 1 segundo, acelera en el otro sentido y se para otra vez.

Está conseguido cuando… en el montaje real, el motor acelera de forma suave en los dos sentidos, con una parada entre medias, y el programa usa tu valor de arranque.

Si te atascas: el programa con huecos

Rellena cada ____: cada hueco es una palabra, un número o un signo que ya has visto en esta página.

// Reto R5: rampa, parada y cambio de sentido
const int EN = 5;
const int IN1 = 8;
const int IN2 = 7;
const int ARRANQUE = ____;        // la velocidad mínima a la que TU motor arranca

void setup() {
  pinMode(EN, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
}

void loop() {
  digitalWrite(IN1, HIGH);       // un sentido
  digitalWrite(IN2, ____);
  for (int v = ARRANQUE; v <= 255; v = v + 5) {
    analogWrite(EN, ____);
    delay(50);
  }
  analogWrite(EN, 0);            // parada
  delay(1000);
  digitalWrite(IN1, ____);        // el otro sentido
  digitalWrite(IN2, ____);
  for (int v = ARRANQUE; v <= 255; v = v + 5) {
    analogWrite(EN, v);
    delay(50);
  }
  analogWrite(EN, 0);
  delay(1000);
}
